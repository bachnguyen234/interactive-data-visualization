# Interactive Data Visualization

A collection of interactive data visualizations exploring patterns across several real-world datasets using Python and Plotly.

The project focuses on transforming data into interactive visual interfaces that allow users to explore relationships, distributions, and trends through filtering, hovering, and direct interaction.

## Visualizations

The project includes interactive visualizations based on:

- Drug-related data
- Healthcare encounter data
- Traveller and travel-related data

Each analysis explores a different dataset and demonstrates interactive approaches to communicating patterns in data.

## Methods

- Interactive scatter plots
- Interactive bar charts
- Filtering and hover interactions
- Exploratory data visualization
- Data aggregation and transformation

## Tools

- Python
- pandas
- Plotly
- Jupyter Notebook
